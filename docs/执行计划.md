# Synapse 一期执行计划（对齐版）

> 说明：本文件保留“计划视图”。代码事实与交接细节以 `docs/开发交接总览.md` 为主。

## 1. 目标

构建本地学习资料库 + AI 助手应用，满足：

1. 导入图文资料到本地独立目录。
2. 异步生成精简总结与详细整理。
3. 提供可观测的流式问答（引用、过程、输出、进度）。
4. 支持资料查看与后续追问。
5. 为平台扩展和多模态扩展预留接口。

## 2. 一期总体路线

### A. 基础设施与协议
- Monorepo、共享类型、REST/SSE 协议、SQLite 迁移。

### B. 导入闭环
- URL 安全校验。
- 抓取、Markdown 转换、文件落盘、判重。
- 适配器分发（通用网页 + 公众号/小红书平台适配）。

### C. AI 异步闭环
- Job 队列与重试。
- 生成 summary / detailed / classify。

### D. 问答闭环
- 渐进式检索（brief -> detailed -> original）。
- SSE 实时阶段更新与答案流。
- cancel + timeout。

### E. 交互闭环
- 四大模块问答界面。
- 资料导入与基础查看。
- 后续补齐详情页、分类树管理、分类过滤交互与设置页。

## 3. 当前实现状态（里程碑）

- 已完成：A、B、C、D 主链路；E 已完成资料详情、分类树管理、历史会话统一入口、引用定位、问答分类过滤与设置页闭环；P0 状态语义（导入/AI 重试/终态失败）已完成首轮收敛；P1 渐进式门控策略调优已落地；P2 已补检索门控与 SSE 状态机 Reducer 单测，并完成公众号/小红书平台抓取基础实作与对应单测。
- 未完成：工程化体系（E2E、打包发布）与多模态扩展。

## 4. 关键约束

1. 前后端隔离，协议先行。
2. LLM 适配层可替换。
3. 资料与衍生文件同目录。
4. 检索坚持渐进式披露。
5. 安全优先（URL、渲染、密钥）。

## 5. 二期预留

1. 音频逐字稿与视频链路实作。
2. 向量检索与混合检索。
3. Electron 打包发布与跨平台增强。
4. 平台抓取深度适配（反爬场景与登录态页面增强）。
